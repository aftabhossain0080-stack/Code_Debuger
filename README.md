# 🛠️ Code Debuger

An AI-powered developer tool that analyzes code errors, explains what went wrong, and helps generate corrected code.

### 🚀 Live Demo

**[Code Debugger](https://code-debuger-vwdn.vercel.app/)**

## ✨ Features

* 🔍 Detect code errors
* 💡 Explain errors in simple language
* 🛠️ Generate corrected code
* 📋 Easy code input and output
* ⚡ Fast, developer-friendly interface
* 🌐 Live web application

## 🧠 How It Works

```text
Enter Code
    ↓
Analyze Error
    ↓
Explain Problem
    ↓
Generate Fix
    ↓
Run / Review Corrected Code
```

## 🛠️ Tech Stack

* React
* Vite
* JavaScript
* Tailwind CSS
* AI-powered code analysis

## 🎯 Use Case

Code Debuger is designed to help developers and students quickly understand programming errors instead of only receiving confusing compiler or runtime messages.
